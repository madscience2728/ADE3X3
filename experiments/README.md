## Status

These implementations are:
- **Not integrated** into the main pipeline
- **Experimental** - may contain alternative approaches
- **Historical** - may represent work-in-progress or abandoned approaches

## Integration

To integrate an experiment into the main pipeline:
1. Review the code in the experimental folder
2. Test thoroughly
3. Move or copy to `src/ade3x3/steps/`
4. Update imports and dependencies
5. Add to pipeline documentation
6. Archive or remove the experiment folder
